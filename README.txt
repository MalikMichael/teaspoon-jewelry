TEASPOON JEWELRY — MULTI-PAGE WEBSITE

Files:
- index.html: Home page
- shop.html: Product catalogue, category and gold/silver filters
- story.html: Our Story page
- custom.html: Custom Orders enquiry page
- styles.css: Shared design
- script.js: Navigation, cart and page interactions
- logo-mark.jpg: Brand emblem

Keep all files together in the same folder. Open index.html to preview locally.
Navigation links connect the four separate pages. The bag count and items persist while the browser tab session remains open.

Important before launch:
- Product images, names and prices are sample placeholders.
- Add your business WhatsApp number in script.js to activate WhatsApp order/enquiry links.
- The shopping bag is front-end only. No database, payment processing or admin dashboard is connected yet.
- Upload all seven files to the ROOT of the GitHub repository, replacing matching files and adding shop.html, story.html and custom.html.
